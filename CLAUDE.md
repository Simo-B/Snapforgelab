## Layout
- Hand-written pages: `index.html`, `replit-app-to-production/` (+ `example-report/`), `deploy-fix/`, `fix-replit-app/`, `prompt-pack/`, `founding-review/`, `free-audit.html`, `hire-replit-developer/`, `about/`, `privacy/`, `terms/`, `tools/replit-readiness-score/`, `404.html`.
- Generated by `python3 scripts/build.py`: guides (`content/guides/*.html`, JSON meta block on top) → `public/guides/**`, guides hub, `sitemap.xml`, `llms.txt`. `STATIC_PAGES` in `build.py` lists hand-written pages for the sitemap. Guides in topics Deployment/Data/Troubleshooting get the Deploy Fix CTA, others the review CTA. Problem/fix guides set `"cta": "fix"` in meta: they get the free-audit + $49 Deploy Fix CTA box and a free-audit mobile CTA; an optional `"steps": [[name, text], ...]` adds HowTo JSON-LD (step anchors `#step-N`). 21 such guides were added 2026-10-16. `"cta": "security"` (Supabase/AI-built app security guides) gives a free audit + $199 review + $49 Deploy Fix box; optional meta `"about"` (JSON-LD subject, default Replit) and `"ogLabel"` (OG image label). Fix guides about another builder can set `"agent"` (CTA wording, default Replit Agent) and `"audit"` (free-audit link, default `/free-audit`), and `"deployFix": false` drops the $49 Deploy Fix offer (its page covers Replit only), as the Lovable guide does. 33 guides total.
- Guide social images: `NODE_PATH=/opt/node22/lib/node_modules node scripts/og.js`, then rebuild. Site image `og.png` is referenced as `/og.png?v=2`.
- Assets: `public/assets/styles.css` and `main.js` load with `?v=N` (now 20). After editing either, bump `ASSET_V` in `build.py` and `?v=` in every hand-written page, then rebuild.
- `main.js`: `PAYMENT_URL` (review), `FOUNDING`, PayPal next-steps note (`NEXT`), Formspree form (`https://formspree.io/f/xjybzkza`) with UTM attribution, sticky mobile CTA.
- Logo: inline SVG; gradient ids must be unique per page (`sfl-logo-h` header, `sfl-logo-f` footer). Files: `logo.svg`, `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`.
- `docs/` (French, not deployed): sales kits, audits, playbooks. `.claude/agents/`: marketing and sales agents.
- MCP Worker (`workers/mcp/`, served at mcp.snapforgelab.com): MCP tool `check_app` (public, surface only: its published contract says it never scans JS bundles, do not change that) and a separate ownership-gated `POST /scan-deep` (`deep-scan.js`) used by `/scan-deep/` (noindex until the endpoint is live). `_worker.js` is generated: `node build-pages-worker.mjs`. Tests: `node test-local.mjs && node test-deep.mjs`.
- Free audit delivery: `scripts/free_audit_check.py` (passive checker; run it outside the cloud container, which cannot reach client sites) and `docs/free-audit-kit.md` (workflow and email templates).
