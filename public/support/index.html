Snapforge Ship-Ready Check — support

The Snapforge Ship-Ready Check is a ChatGPT plugin that runs a quick, read-only launch check on a live app you own or are authorized to test, built with Replit, Lovable or Bolt.

What it checks

It looks only at what any visitor's browser already sees on your app's public URL:

  • Whether the app is reachable and how fast it responds.
  • SEO basics: page title and meta description.
  • robots.txt and whether sitemap.xml returns real XML.
  • Security response headers (HSTS, CSP, X-Frame-Options, X-Content-Type-Options).
  • Whether CORS is open to any site.
  • A builder dev banner or dev script left in production.

For each issue it can hand you a paste-ready prompt for your builder (Replit Agent, Lovable or Bolt).

What it does not do

It is strictly read-only. It never scans your JavaScript bundles for secrets, never signs in, never submits a form, never writes anything and never reads a database. It only reads your app's own public responses. Private and internal addresses are refused.

For a deeper look (exposed keys, authorization between users, database rules), request the free Snapforge Lab audit, which confirms you own the app first.

How to use it

  1. Open the Snapforge Ship-Ready Check in ChatGPT.
  2. Paste the public URL of your app, for example https://yourapp.replit.app.
  3. Read the results, then ask for the fix prompt for any issue and paste it into your builder.
