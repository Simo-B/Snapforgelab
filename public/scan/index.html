        What the 1-click scanner checks
        
    
          
      
        • Secret keys in your JavaScript: Stripe live/test secret keys, OpenAI and Anthropic keys, AWS keys, GitHub tokens, Supabase service_role and secret keys, plus Stripe test mode left in production. Secrets are always masked to the last 4 characters.
          • 
      
        • Supabase tables & Storage buckets: uses only the public key your app already ships to ask each table once for 1 row and check if Storage buckets allow anonymous file listing. Zero row data or file names are ever read or stored.
          • 
      
        • Auth redirects & open CORS: password-reset or magic-link callbacks pointing to preview/localhost domains, and servers reflecting foreign Origins with credentials enabled.
          • 
      
        • Headers, cookies, source maps & SEO: HSTS, CSP, X-Frame-Options, nosniff, Referrer-Policy, cookie security flags, publicly exposed .map source files, dev banners, robots.txt and sitemap.xml.
