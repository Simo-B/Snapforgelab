FAQ

What is an MCP server?

MCP (Model Context Protocol) is the open standard ChatGPT and Claude use to call outside tools. An MCP server for your app lets a user ask ChatGPT or Claude to do something in your product, and the assistant calls your app to do it.

Is it safe?

Tools are read-only by default. Any tool that changes data needs your OK, and every call goes through an API key or OAuth tied to the user's own account, so nobody can reach someone else's data.
