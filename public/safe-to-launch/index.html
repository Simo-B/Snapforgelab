What I check

  • Exposed keys and secrets: API keys shipped to the browser or left in the code.
  • Database access rules: who can read and write what, table by table.
  • Login and accounts: users opening other users' data, broken redirects, weak sessions.
  • Payments and webhooks: nobody can fake a "payment succeeded".
  • Deploy and environment settings: production config, dev and prod kept apart.
  • Backups: they exist, and they can actually be restored.
